## 🔧 CONFIGURATION

### To Customize Colors
Edit `/frontend/tailwind.config.cjs`:
```javascript
colors: {
  cyberblack: '#0a0e27',  // Change primary background
  neon: '#00e5ff',        // Change accent color
}
```

### To Change Animation Duration
Edit `/frontend/src/index.css`:
```css
@keyframes float {
  /* Change 6s-12s to your preferred duration */
  animation-duration: 8s;
}
```

### To Adjust Particle Count
Edit each page component:
```javascript
Array.from({ length: 15 })  // Change 15 to desired count
```
